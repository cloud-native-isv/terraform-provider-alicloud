## Overview

This feature governs naming consistency for Alibaba Cloud Log Service Terraform resources and data sources. It standardizes user-facing naming to `alicloud_log_*`, while defining migration governance from historical `alicloud_sls_*` names to reduce ambiguity and external integration cost.
