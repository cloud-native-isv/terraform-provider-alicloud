## Overview

Comprehensive testing strategy including:
- **Unit Tests**: For pure logic, utility functions, and schema validation.
- **Acceptance Tests (AccTest)**: Using Terraform Plugin SDK's testing framework to provision real infrastructure and verify state.
- **Linting**: Static analysis via `go vet`, `staticcheck`, etc.

## Latest Review
