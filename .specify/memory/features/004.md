# Feature Detail: Local SDK Vendor Management

**Feature ID**: 004  
**Name**: Local SDK Vendor Management  
**Description**: Management of local SDK copies in `sdk/` directory for specific service versions.  
**Status**: Implemented  
**Created**: 2026-01-22  
**Last Updated**: 2026-01-22

## Overview

Unlike standard Go projects that rely wholly on `go.mod`, this provider maintains local copies of certain Alibaba Cloud service SDKs in the `sdk/` directory (e.g., `foasconsole`, `ververica`). This ensures build stability and allows for specific patch application if necessary.

## Latest Review

Structure visible in repository root (`sdk/` folder).

## Key Changes

1. Directory structure `sdk/` established for vendored code.
2. `go.mod` configured to use local replacements or paths where applicable.
3. Manual update process for these SDKs.

## Implementation Notes

- Requires careful management to ensure local copies don't drift unintentionally from upstream if not desired.
- Doc comment in README explicitly mentions this deviation from open-source norms.

## Future Evolution Suggestions

- Evaluate if local vendoring can be replaced by standard module versioning for all services.
