# Feature Detail: Strong Typing Enforcement

**Feature ID**: 006  
**Name**: Strong Typing Enforcement  
**Description**: Mandate strict usage of defined structs over weakly typed maps.  
**Status**: Implemented  
**Created**: 2026-01-22  
**Last Updated**: 2026-01-22

## Overview

To ensure code maintainability and reduce runtime errors, the project strictly enforces the use of strong types (structs, enums) provided by `cws-lib-go` or internal packages. The usage of `map[string]interface{}` or `interface{}` for API payloads is prohibited for new code.

## Latest Review

Explicitly added to Constitution (Article V) and Development Guide.

## Key Changes

1. Code reviews flag usage of `map[string]interface{}`.
2. Refactoring of legacy code to use defined structs.
3. API definitions in `cws-lib-go` updated to support all field needs.

## Implementation Notes

- Exception: Interacting with legacy code paths that strictly require maps (read-only mode).
- Bridging adapters allowed temporarily if `cws-lib-go` is missing a type definition (requires Todo/Justification).

## Future Evolution Suggestions

- Static analysis tools (linters) to automatically reject new `map[string]interface{}` usages.
