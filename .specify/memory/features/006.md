# Feature Detail: Local SDK Management

**Feature ID**: 006  
**Name**: Local SDK Management  
**Description**: 使用 sdk/ 目录固定关键 SDK 版本  
**Status**: Implemented  
**Created**: 2026-02-06  
**Last Updated**: 2026-02-06

## Overview

Maintain local copies of specific Alibaba Cloud SDKs in the `sdk/` directory.
This ensures stability and reproducibility by avoiding upstream breaking changes or dependency conflicts (diamond dependencies) often found with generated SDKs.

## Latest Review

`sdk/` directory contains `foasconsole-20211028` and `ververica-20220718`.
Project build path includes these local packages.

## Key Changes

1. Creation of `sdk/` directory structure
2. Import path adjustments to point to local SDKs
3. Documentation clarifying why local SDKs are used (vs `go.mod` deps)

## Implementation Notes

- Use local SDKs only when necessary (e.g., customized logic, critical bug fixes not yet upstreamed, or version locking).
- Main SDKs (ECS, OSS) still tend to come from `go.mod` (aliyun-alibaba-cloud-sdk-go), but specific service SDKs may be local.

## Future Evolution Suggestions

- Regularly evaluate if local SDKs can be replaced by official module versions
- Tooling to automate the update/sync of local SDKs from upstream
