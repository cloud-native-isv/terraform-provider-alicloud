## Overview

Integrate `github.com/cloud-native-tools/cws-lib-go` to normalize API interactions.
This library provides strong typing for API requests/responses, replacing untyped maps, and standardizes error handling and logging.

## Latest Review

`go.mod` includes `cws-lib-go`. New services utilize this library for API structs.
Adoption is enforced via code review and Engineering Standards.

## Key Changes

1. Dependency added to `go.mod`
2. Service layer updated to import `cws-lib-go/lib/cloud/aliyun/api`
3. Custom error types mapped to cws-lib-go standard errors
