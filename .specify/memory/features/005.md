# Feature Detail: CWS-Lib-Go Integration

**Feature ID**: 005  
**Name**: CWS-Lib-Go Integration  
**Description**: 统一 API 调用封装与强类型接口 (cws-lib-go)  
**Status**: Implemented  
**Created**: 2026-02-06  
**Last Updated**: 2026-05-15

## Overview

Integrate `github.com/cloud-native-tools/cws-lib-go` to normalize API interactions.
This library provides strong typing for API requests/responses, replacing untyped maps, and standardizes error handling and logging.

## Latest Review

`go.mod` includes `cws-lib-go`. New services utilize this library for API structs.
Adoption is enforced via code review and Engineering Standards. The 2026-05-14 CMS Provider refactor specification extends this integration to the CMS service files enumerated by the requirement workflow. The 2026-05-15 plan records the CMS scope matrix, service-layer migration contract, and validation workflow for this extension. The 2026-05-15 tasks breakdown adds an MVP-first sequence for migrating `alicloud_cms_service`, then filling CMS object service wrappers and compatibility evidence.
The 2026-05-15 implement phase completed US1/US2/US3 scope artifacts for spec `007-refactor-cms-api`: `alicloud_cms_service` now goes through provider service methods, 16 CMS object-group service files are promoted from one-line placeholders to explicit blocked-capability stubs, and compatibility/layering tests plus evidence files were added. Remaining gaps are tracked as external blockers: pre-existing compile mismatches in local `pkg/cws-lib-go/lib/cloud/aliyun/api/cms` and unrelated compile failures in existing provider package tests.
